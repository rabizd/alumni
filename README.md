## Hakkında

**Alumni**, mezunların birbirleriyle ve okullarıyla bağını canlı tutmayı amaçlayan bir web uygulamasıdır. Mezunların iletişim bilgilerini, çalıştıkları kurumları ve kariyer geçmişlerini tek bir yerde toplar; böylece mezunlar ağını keşfetmek ve iletişim kurmak kolaylaşır.

- 📝 Mezunların kariyer güncellemelerini eklemesi
